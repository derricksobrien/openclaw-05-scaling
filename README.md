# Scaling from 6 to 60 Nodes

> **Track:** OpenClaw Real-World Lab Build (Track 3)
> **Course 5 of 5**

Design the infrastructure, cost model, and runbook for scaling the Mac Mini lab by 10x.

---

## Modules

### Module 1: Infrastructure as Code with Terraform

**Learning Objectives:**
- Define lab infrastructure in Terraform HCL
- Apply and destroy environments reproducibly
- Manage state files safely in remote backends

### Module 2: Service Discovery & DNS for Lab Nodes

**Learning Objectives:**
- Deploy Consul for service discovery
- Configure DNS-based load balancing
- Implement health-check-driven routing

### Module 3: Cost Analysis: Mac Mini vs. Cloud

**Learning Objectives:**
- Calculate 3-year TCO for 60 Mac Minis
- Compare against equivalent AWS/GCP instances
- Model break-even point for lab vs. cloud

### Module 4: Migration Runbook for Node Additions

**Learning Objectives:**
- Document the zero-downtime node addition process
- Automate new node provisioning with Ansible
- Validate new node integration with smoke tests
